## プロジェクト概要

■ 概要

本プロジェクトは、2Dアクションゲームとして基本操作からボス戦まで一通りのゲームループを実装した。
特に「状態管理」と「演出制御」の設計に重点を置いている。

■ 設計（コア部分）

・状態管理（最重要）

ボス戦およびプレイヤー状態の管理にステートマシンを採用。
攻撃・待機・形態変化などの状態を明確に分離し、状態遷移条件を制御することで、処理の競合や不整合を防止した。
（例：複数の攻撃処理が同時に発火する問題を防止）

・HP管理システム

プレイヤーと敵で共通利用できるHP管理クラスを設計。
シーン遷移後も値を保持できるようにし、ゲーム進行の一貫性を確保した。

■ 実装（ゲームプレイ）

・プレイヤー操作

移動・ジャンプなどの基本操作を実装し、スマートフォン操作にも対応。

・敵AI

敵キャラクターごとに異なる挙動を持つよう設計。
例：ツタ → 固定攻撃型、ハエ → 移動追従型

・進行管理

ゴール判定、リスポーン（セーブポイント）、シーン間データ引き継ぎを実装。

■ 演出・体験設計

・カメラ制御

ズーム・画面揺れを実装し、ボス戦時の演出を強化。

・UI/UX

タイトル画面、自動デモ切り替え、チュートリアルを実装。

・サウンド

BGM・SEを導入し、ゲーム体験を補強。

■ 工夫・改善点

・状態管理の明確化により、機能追加時の影響範囲を限定

・処理の責務分離により、スクリプトの可読性を向上

・演出とロジックを分離し、調整しやすい構造にした

## 開発メンバーと担当箇所

プロジェクトの開発に貢献したメンバーと、それぞれの主な実装箇所は以下の通りです。

### sogotoya
* ボス戦の実装(ステートマシンを用いた攻撃パターンの構築、落雷機能、形態変化など)
* タイトル画面の作成(自動操作デモの切り替え機能やUI表示)
* 演出面の強化(カメラのズーム機能、画面の揺れ、一時停止機能、各種アニメーション)
* サウンド機能の組み込み(BGMやSEの追加)
* チュートリアルギミックの実装
* 敵キャラクター「ツタ(Tsuta)」の実装
* HP管理システムのベース作成

### Mokou (Mokou2005 / Mokou2201207)
* プレイヤーの基本操作(移動、ジャンプなどのキャラクター操作)
* ゲームオーバー処理とリスポーン(セーブポイント)機能の実装
* ステージマップの作成とブロックギミックの構築
* 敵キャラクター「ハエ(Fly)」の実装
* シーン間のデータ引き継ぎ(HPなどの値の保持)
* コインによる回復機能の導入
* スマートフォン向けUIと操作対応
* ゴール判定機能の実装
